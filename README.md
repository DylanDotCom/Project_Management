GISMO – Cartoon Discovery Platform

1. Project Overview

GISMO is a cartoon discovery and cataloguing platform designed for cartoon and animation enthusiasts. The website acts as a centralised depository where users can explore, discover, search for and keep track of their favourite cartoons.

GISMO aims to provide users with an easy and enjoyable way to rediscover beloved cartoons, find out where they are available to watch and organise their personal cartoon collections.

The platform also includes user profiles and a blog section, creating a community space for people who share an interest in cartoons and animation.

2. Main Features

The GISMO website will include the following features:

Cartoon Database: A centralised collection of cartoons where users can browse and explore different animated shows and films.
Search Functionality: Allows users to search for specific cartoons and discover new ones.
Cartoon Information Pages: Individual pages containing information about each cartoon, such as its description, genre, release date and other relevant details.
Where to Watch: Provides information on where users can stream or watch particular cartoons.
User Profiles: Allows users to create and manage their own personal accounts and profiles.
Blog Page: A dedicated section featuring cartoon-related articles, reviews, news and other animation-related content.

3. Project Objectives

The main objectives of GISMO are:

To create an accessible and user-friendly cartoon discovery platform.
To make finding information about cartoons easier.
To help users discover where their favourite cartoons are available to watch.
To allow users to create personalised collections of cartoons.
To encourage interest and engagement within the cartoon and animation community.

Additional frameworks, libraries, databases and development tools will be added to this section as the project progresses.

5. Website Structure

The website will consist of the following main sections:

Home Page: The main landing page introducing GISMO and displaying featured or recommended cartoons.
Explore/Search Page: Allows users to browse and search the cartoon database.
Cartoon Details Page: Displays information about individual cartoons, including where to watch them.
User Profile Page: Displays a user's profile and saved cartoons.
Blog Page: Contains articles, reviews and news relating to cartoons and animation.
